# Claire-Tian

A development project starting with a website, expanding into social media management, and eventually supporting a multi-model processing system.

## Website

The site is a plain static page served by GitHub Pages at https://www.claire-tian.com.

- `index.html` is the whole home page (styles and script are inside it).
- `CNAME` tells GitHub Pages which domain to serve.
- To preview, open `index.html` in a browser.
